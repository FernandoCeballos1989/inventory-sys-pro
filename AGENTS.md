# AGENTS.md

## Stack

- **Backend**: Laravel 12, PHP ^8.2, SQLite (default)
- **Frontend**: Vue 3 + TypeScript, Inertia.js v2, Tailwind CSS v4, shadcn-vue (new-york-v4 style)
- **Auth**: Laravel Fortify (registration, password reset, 2FA enabled; email verification in config but User model does not implement `MustVerifyEmail`)
- **Route binding**: laravel/wayfinder — generates TypeScript route helpers
- **Testing**: Pest 3 with RefreshDatabase (in-memory SQLite)
- **Mail**: Resend (`resend/resend-php`), `MAIL_FROM_ADDRESS=inventory-sys-pro@shorai-lab.com`

## Commands

```bash
# Full dev environment (server + queue + vite, concurrent)
composer dev

# Setup from scratch
composer run setup

# Build frontend assets
npm run build

# Typecheck frontend
npx vue-tsc --noEmit

# PHP lint (fix)
composer lint

# PHP lint (dry-run only)
composer test:lint

# Run all checks (lint + tests)
composer test

# Run Pest directly
php artisan test
# or
./vendor/bin/pest

# Frontend format (fix)
npm run format

# Frontend format (check only)
npm run format:check

# Frontend lint (fix)
npm run lint
```

**Required order before committing**: `composer lint` → `composer test` (lint runs inside `composer test` but `composer test` clears config cache first).

## Auto-generated code — do not edit manually

- `resources/js/wayfinder/` — Wayfinder route definitions (regenerated by Vite plugin)
- `resources/js/routes/` — route helper wrappers (regenerated by Vite plugin)
- `resources/js/components/ui/` — shadcn-vue primitives (managed by `npx shadcn-vue@latest`)

These directories are excluded from Prettier and ESLint via `.prettierignore` and `eslint.config.js` ignores.

## Key conventions

- **Pint preset**: `laravel` (see `pint.json`)
- **Prettier**: single quotes, semicolons, tabWidth 4, `prettier-plugin-tailwindcss` (class sorting)
- **ESLint**: `vue/multi-word-component-names` off, `@typescript-eslint/no-explicit-any` off, `consistent-type-imports` (separate type-imports), `import/order` enforced (alphabetized)
- **EditorConfig**: 4-space indent, LF line endings, UTF-8
- **Testing DB**: SQLite `:memory:` (set in `phpunit.xml`)
- **Demo sandbox**: `DemoSandbox` middleware provides per-session SQLite isolation. Each session gets a copy of `database/demos/master.sqlite` as `demo_{sessionId}.sqlite`. Writes go to the session copy, not the master. **No-op in production** (`APP_ENV=production`). Expired copies (≥1h) are cleaned hourly by `demo:clean` (scheduled in `routes/console.php`, runs via supervisord scheduler).

## Docker & deployment

- **Single container**: Nginx + PHP-FPM + supervisord (manages queue worker + scheduler)
- **Database**: SQLite — persisted via Docker volumes (`app-db`, `app-storage`)
- **Entrypoint**: runs `artisan migrate --force`, `config:cache`, `route:cache`, `view:cache` then starts supervisord
- **Build**: two-stage Dockerfile — `frontend` stage runs `npm run build`, `app` stage assembles PHP + Nginx
- **Ports**: app binds to `127.0.0.1:10011` by default (configurable via `APP_PORT` in `.env`)

```bash
# Build and run (production)
docker compose -f compose.yaml -f compose.prod.yaml up -d --build

# First deploy — generate APP_KEY
docker compose exec laravel.test php artisan key:generate
docker compose exec laravel.test php artisan migrate --force
# Then restart to apply config cache
docker compose restart laravel.test

# Useful commands
docker compose logs -f laravel.test
docker compose exec laravel.test php artisan migrate --force
docker compose exec laravel.test php artisan optimize:clear
```

**VPS deployment pattern** (inventory.shorai-lab.com → port 10011):
- DNS A record in Cloudflare (proxied)
- Nginx vhost proxying to `127.0.0.1:10011`
- certbot SSL certificate
- No new UFW rules needed (only 22/80/443 open)
